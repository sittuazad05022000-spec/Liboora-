## 1. ⭐ Question

> ⭐ **What is the proposed `SRCHPO-1` V1 canonical script set for `BC-23`, as filed under
> Step 1 of the authorised `PRD-015` v0.2 amendment route?**

This ADR proposes the value change that `Accepted` `ADR-0174` released for filing. The
proposed value narrows `SRCHPO-1` to a **single** canonical V1 script set member for
V1: **English (Latin script) only**. **Hindi (Devanagari)** is **removed from the V1
closed set and scheduled to V2** (scheduled, not waived — V2 still owes it).
